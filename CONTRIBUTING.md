# Contributing to cperl-mode

If you found a bug, or have an idea for improving cperl-mode
please don't hold back!

cperl-mode.el in the "upstream" branch in this repository is a mirror
(not always up to date) of cperl-mode.el from the "master" branch of
the
[GNU Emacs repository](https://cgit.git.savannah.gnu.org/cgit/emacs.git).
It may contain features which have not yet been released with an
Emacs, but they might be available from GNU ELPA.

Therefore, code contributions have to adhere to Emacs coding
conventions, as detailed in the
[CONTRIBUTE](https://cgit.git.savannah.gnu.org/cgit/emacs.git/plain/CONTRIBUTE)
file in that repository.  It deserves a careful read!

To contribute, you do not need to clone the
Emacs repository or build Emacs from source, though.  You can test
your code against a recent Emacs distribution.
